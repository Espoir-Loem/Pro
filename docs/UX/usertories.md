# Histoires utilisateur

**Statut** : version 2, 25 novembre 2026
**Rôle** : alias historique. Le backlog canonique est [userstories.md](./userstories.md).

`usertories.md` est l'ancien nom conservé pour les liens historiques. La version corrigée `userstories.md` contient les dix-sept histoires, leurs priorités P0 et P1 et leur rattachement à O1 à O5 ou H1 à H9.

## Ce que contient le fichier canonique

- Dix-sept histoires nommées US-01 à US-17, chacune reliée à une fonction FS du [PRD](../Product/prd.md).
- Une colonne Opportunité ou hypothèse renseignée avant l'entrée en sprint, avec O1 à O5 ou H1 à H9.
- Des priorités P0 pour le MVP et P1 pour la phase suivante, sans priorité sur une décision ouverte.

## Règle de mise à jour

Toute correction du backlog se fait dans `userstories.md`, puis est répercutée dans le [PRD](../Product/prd.md) et la [recherche UX](./ux-research.md). Cet alias ne contient pas de backlog propre : il ne doit pas être édité pour modifier une histoire.
