# Variante B, étape email, J8

**Version** : v1, préparée le 26 novembre 2026  
**Statut** : formulation prête, aucune exposition enregistrée  
**Hypothèse** : H4

## Phrase présentée

Avant d'envoyer votre message, donnez votre email. Il sert seulement à vérifier qui vous êtes auprès de la personne que vous avez choisie.

## Règle de mesure

Une seule mesure d'abandon par variante. L'adresse saisie est l'adresse de test fournie par l'équipe, jamais une adresse réelle. Abandon : quitter l'étape sans saisir l'adresse de test ou refuser la variante. Aucune autre question n'est posée dans cette variante.
