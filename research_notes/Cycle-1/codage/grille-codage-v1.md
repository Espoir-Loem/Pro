# Grille de codage, version 1

**Statut** : prête le 26 novembre 2026, aucune fiche codée  
**Responsable** : Espoir LOEMBA, intérimaire  
**Règle** : deux personnes codent la même fiche. Aucune interprétation libre ajoutée après coup.

| Code | Ce qui est codé | Identifiant relié |
|---|---|---|
| `GESTE-JUGEMENT` | Geste observable avant l'opinion déclarée | H1, H2 |
| `FRICTION` | Blocage ou hésitation observé | H3, H4, H7 |
| `EMOTION` | Manifestation visible, jamais déduite d'un ton de voix seul | H1, H4, H5 |
| `SIGNAL` | Signal de confiance ou de suspicion cité par la personne | H2, H5, O4 |
| `REFUS` | Refus d'enregistrement, de code ou de variante | H4 |

## Procédure

1. Coder le geste avant de lire ou d'écrire l'opinion déclarée.
2. Noter la ville, le secteur et la plateforme sur la fiche.
3. Coder la même fiche à deux, puis comparer les codes.
4. Écrire chaque désaccord dans [desaccords.md](./desaccords.md) avec les deux interprétations.
5. Ne pas arbitrer un désaccord par la seule ancienneté d'une personne dans l'équipe.

Un constat entre dans le PRD seulement avec une citation relue par la personne participante ou une observation codée, et avec une ville. Aucun constat n'est inscrit dans cette grille à la date de préparation.
